MiniCalendar — Improved

Navegación rápida por mes y año + botón "Hoy" + modo compacto

Problema actual

Solo hay 2 flechas ‹ › para navegar mes a mes. Para ir de Abril 2026 a Enero 2024 necesitas 27 clicks. No hay forma de saltar a un año o mes directamente.

1. Vista normal — Calendario

Tap en "Abril 2026" abre el selector de mes. El título es clickeable. Botón "Hoy" al fondo para volver rápido.

2. Selector de mes — Tap en "Abril 2026"

Al tocar el título se muestra la grilla de 12 meses. Las flechas ‹ › ahora navegan años. Tap en un mes vuelve a la vista de calendario en ese mes.
2026

3. Selector de año — Tap en "2026"

Al tocar el año en la vista de meses, se muestra una grilla de 12 años. Las flechas navegan en bloques de 12 años. Tap en un año vuelve al selector de mes.
2020 — 2031

4. Flujo de navegación

Calendario — tap título — Meses — tap año — Años
Cada nivel "zoom out" muestra más. Seleccionar un item "zoom in" de vuelta.
"Hoy" siempre visible — vuelve directo al calendario en la fecha actual.

5. Props — Existentes + Nuevas

Prop Tipo Default Descripción
selectedDate string? — Fecha seleccionada (YYYY-MM-DD)
onDateSelect (date) => void — Callback al seleccionar un día
eventDots Record<string, number> {} Dots de eventos por fecha
showMonthPicker NEW boolean true Permitir seleccionar mes desde grilla
showYearPicker NEW boolean true Permitir seleccionar año desde grilla
showTodayButton NEW boolean true Mostrar botón "Hoy" al fondo
minDate NEW string? — Fecha mínima navegable (YYYY-MM-DD)
maxDate NEW string? — Fecha máxima navegable (YYYY-MM-DD)
onMonthChange NEW (year, month) => void — Callback al cambiar de mes (para cargar dots dinámicamente)
className string '' Clases CSS adicionales

6. Mobile — Full-width

En mobile el MiniCalendar no se usa en sidebar (está oculto). Se muestra full-width cuando se usa como popover o standalone. Los botones de día se agrandan a 36px para touch targets adecuados.
