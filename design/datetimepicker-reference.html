DateTimePicker

Componente combinado: CalendarGrid + TimePicker en un solo popover

1. Input trigger

Un solo input readonly que muestra fecha + hora formateadas. Click abre el popover completo.

2. Popover — Desktop

Calendario arriba (CalendarGrid reutilizado), selector de hora abajo. Hora se muestra como dos inputs clickeables (abren TimePicker individual). Botón "Ahora" setea fecha+hora actual. "Confirmar" cierra el popover.

4. Composición interna

DateTimePicker reutiliza componentes existentes:

Popover
├── Input (trigger, readonly, muestra "fecha — hora")
├── PopoverContent
│   ├── CalendarGrid (existente, con month/year picker)
│   ├── Divider
│   ├── TimePicker (existente, input que abre su propio popover)
│   └── Footer ("Ahora" + "Confirmar")

No se duplica lógica. CalendarGrid maneja la fecha, TimePicker maneja la hora. DateTimePicker solo combina ambos valores en un ISO string y gestiona el popover externo.
